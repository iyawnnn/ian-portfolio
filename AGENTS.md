# AGENTS.md

## Project overview

Personal portfolio site for Ian Macabulos, built with Next.js 15 App Router, TypeScript, and Tailwind CSS.

Package manager is `pnpm`. Do not use npm or yarn.

This is an existing portfolio redesign. Preserve the established architecture and visual language unless the requested task explicitly requires changing them.

pnpm build
